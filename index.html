量子回路を「安く」作るコンペで、これまでやったこと

量子コンピュータの予備知識がなくても読めるように、図を使いながら順に説明します。中心は invsqrt 課題です。ゼロから作った回路を約 12 倍、公開回路の取り込みと改良を合わせて約 34 倍まで安くした道のりをたどります。末尾の「日々の記録」に、毎日の動きを書き足していきます。

最終更新 2026-11-25（確定 LB 33.21011、54位 / 3,685チーム）

そもそも何を競っているのか

Google Quantum AI が出した 3 つの計算（課題）を、量子回路としてできるだけ安く組むコンペです。「安い」とは主に次の 2 つが少ないことを指します。

qubit 数 Q
回路が同時に使う量子ビットの本数です。実機では qubit が貴重なので、少ないほど良くなります。
Toffoli 数 C
「2 つの入力が両方 1 のときだけ出力を反転する」ゲート（AND に相当）の数です。量子計算機では飛び抜けて高価な操作なので、コストの目安として数えます。細かい回転ゲートも Toffoli 何個分かに換算して足します。

課題ごとに「ベースラインの回路より何倍安いか」を計算し、3 つの倍率の幾何平均が順位表（LB）の点数になります。どれか 1 課題を 8 倍良くすると、LB は 81/3 = 2 倍になります。

「検証できる」がミソ。提出した回路は、運営の verifier（検証プログラム）が古典シミュレーションで正しさを確かめます。invsqrt は全入力、dqi などは定められた入力と測定結果のサンプルで調べます。間違った回路は 0 点です。手元でも同じ verifier を動かせるので、提出前に必ず PASS を確認しています。

invsqrt 課題：何を計算する回路か

以下の「表 + 二次式」はゼロから作った回路の説明です。現在採用している公開 Q46 版は、平方根と割り算を少しずつ計算する別の方式です。

22 bit の整数 x を受け取り、x 自体は変えずに、量子状態に「位相」e2πi/√x だけを付けます。位相は「回転の角度」のようなもので、測定しても直接は見えません。その角度に 1/√x を書き込む、という課題です。

量子回路には特有のルールがあります。計算の途中で使った作業用 qubit は、最後に必ず 0 に戻す（逆計算する）必要があります。散らかしたままだと、位相がきれいに付きません。そのため回路全体は「計算 → 位相を付ける → 同じ計算を逆向きにたどる」という往復の形になります。

なぜ「表 + 多項式」なのか

1/√x を量子回路で直接割り算や平方根として計算すると、非常に高くつきます。そこで x の範囲を小さな区間に切り、区間ごとに「この区間では 1/√x ≈ c₀ + c₁t + c₂t²」という二次式の係数を表にしておきます。回路は「x の上位ビットで表を引く → 下位ビット t で二次式を計算する」だけで済みます。区間を細かくするほど式は簡単になりますが、表は大きくなります。この兼ね合いを探索プログラム（search.py）で決めました。今の設計は 512 区間（a=9）× 二次式です。

精度の条件。位相の誤差は全入力で 2⁻²⁴/√x 回転以内でなければなりません。係数の桁数を削るほど回路は安くなりますが、誤差が増えます。そこで、切り捨てまで含めて 1 ビット単位で一致する数値モデルを作り、回路を作る前に全 313 万入力の誤差を確かめています。

Toffoli と Qubit をどう削ぎ落としたか：削減の全工程

invsqrt のスコアは Q（qubit数）× C（Toffoli換算コスト） で決まります。どちらか片方だけを減らしても良いスコアは出ません。しかも、現在の自前回路（Q=84, C≈2,060）では、「qubit を 1 本減らす」ことは「Toffoli を約 24 個減らす」のと同等のインパクトを持ちます。そのため、「Toffoli が少し増えてでも qubit を削る」という大胆なトレードオフが勝利の鍵になります。ベースラインの 208 万点から 17.3 万点（約 12 倍改善）に至る削減の工程は、大きく 5 つのフェーズに分かれます。

工程 1

アルゴリズムの抜本刷新（Toffoli 7,735 → 2,476、Q 260 → 132）

運営のベースラインは 1/√x を直接割り算と平方根で求めており、膨大なゲートを消費していました。これを「区間ごとの表引き（QROM）＋ 二次多項式近似（Horner 法）」へと完全に作り替えました。さらに、狭い桁を広い桁に足す際に余分なゲートを使わない自前の Gidney 型加算器や、上位ビットが 0 である性質を生かした降順 CSWAP シフタを導入。Toffoli を一気に 3 分の 1 以下に圧縮しました。

工程 2

Qubit の「満員電車」を解消する構造改革（Q 132 → 94）

Toffoli が減っても Q=132 ではスコアが伸び悩みます。ピークを押し上げていた係数レジスタと加算器の幅を大胆に削りました。

  • lo_bits（上下分割）：多項式の定数項 c₀ は区間内での変化が小さいため、動かない上位を別のレジスタ Yh に逃がし、加算器が扱うのは下位 21 bit のみに限定。qubit と Toffoli の両方が劇的に減少（Q 102、score 203k）。
  • early_hi（先行位相付与＆即時消去）：量子回路の位相は「足し算」で重ね合わせられる性質を持ちます。これを利用し、表を引いた直後に Yh の分の位相を先に付け、Yh をその場で消去（unlookup）して多項式計算の間は qubit を解放しました。Toffoli は一時的に 47 個増えましたが、Q が 94 へと 8 本減り、スコアは 19.8 万点へ向上しました。
工程 3

無駄な桁・繰り上がりの切り詰めと線形計画法（Toffoli 1,795 → 1,733、Q 94 → 90）

構造が決まった後は、ビット単位の極限最適化を進めました。

  • trim（変動しない上位ビットの加算削除）：313 万全入力の厳密数値シミュレーションを行い、足し算の前後に実際に値が変わりうる最上位桁を特定。絶対に繰り上がりが届かない無駄な桁を加算器から切り落としました（Toffoli −50、score 194k）。
  • windowed adder ＋ borrow_top：繰り上がりの長い連鎖を途中で区切って測定・後補正する窓付き加算器を導入。さらに、作業領域の最上位 1 本を入力 x の「必ず 0 であるビット」から一時借用し、Z 回転で打ち消すことで Q を 91 へ圧縮（score 190k）。
  • LP（線形計画法）による角度調整：回転角を 2⁻ᵏ の固定値からわずかに微調整して誤差を打ち消し合わせ、浮いた精度マージンを使って係数 c₁ を 1 bit 削減。Q 90、回転数 45 個を達成（score 184k）。
工程 4

作業領域ゼロの論理合成（XAG）と極限最適化（Q 90 → 84、Toffoli 1,771 → 1,718）

従来の unary 表引きでは作業用 qubit（ancilla）が最低 9 本必要で、Q 90 が物理的な下限になっていました。これを突破するため、公開最良版が使っている「作業用 qubit を一切使わない論理回路網（XAG）」の自前合成に乗り出しました。

  • thick 方式（足場の拡張）：単純なエシェロン合成では 526 AND と重く unary 版に負けていましたが、出力空間の足場を先回りして厚くする「thick 方式」を考案し、383 AND まで一気に圧縮。Q 84 を実現し、ついに 17.8 万点へ突入。
  • Rust 移植による 12 倍高速化：合成エンジンを Python から Rust へフルスクラッチ移植。合成時間が 9 分から 45 秒へと 12 倍速くなり、広範なシード探索が可能に。
  • lastu による r-1 積展開の再最適化（最新）：Rust で得られた論理回路の各出力ビットに対し、SAT/分枝限定法（lastu）で r-1 積展開を再探索。56 出力中 48 出力で AND ゲートを 1 個ずつ削減（計 −48 AND）。Toffoli 平均 1,718 を叩き出し、自前最良となる 173,797（約 12.0 倍改善） を達成しました。
工程 5（進行中）

ボトルネックの完全解剖と Q 84 → 83 化

Q 84 での qubit 使用ピークを詳細に解析した結果、ボトルネックは「early_hi での一時的な 3 本」と「多項式段 0 の加算器キャリー 11 本」にあることを突き止めました。その後 Q 83 化も試しましたが、後片付けの操作が増えて約 197,736 に悪化しました。この系列の最良は 173,797 のままです。

qubit の混雑はどう変わったか：Q 83 → 46

図を 11/15 の現行採用回路で測り直しました。比較するのは、旧自前の最良（Q=83）と、独自の繰り上がり近似を 7 か所に入れた現行回路（Q=46）です。Q は回路に用意した qubit の総本数。下の線は、そのうち入力用の 22 本を除いた場所が、処理の途中でどのくらい使われるかを表します。

現行の回路で、入力用以外に用意する領域は24 本。今回のサンプル計測でもピークは 24 本でした。旧自前版はサンプル中に最大 60 本が使われ、用意する領域は 61 本です。現行は、平方根と割り算を少しずつ進める計算方式を使い、入力 x の空いた桁も作業場所にしています。さらに今回は、補正積の繰り上がり 7 行を近似し、全入力で位相を合わせ直しました。図から除いた入力用の 22 本でも計算している点に注意してください。

その後、Q 44 へ。この図を測った翌日（11/16）、他チームが qubit を 44 本に減らした版を公開し、いまはそちらを使っています。次の課題は Q 44 → 43。1 本減らせれば約 2.3% 安くなりますが、混雑する瞬間が回路のあちこちに散らばっていて、まだ手がかりはありません。
